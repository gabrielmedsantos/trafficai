1. Definições

  • Cliente Empresarial: pessoa jurídica que contrata a Lowan CRM e usa a Plataforma para gerenciar atendimento a seus próprios leads.
  • Lead: pessoa física cujos dados de contato (nome, telefone, mensagens) são tratados pelo Cliente Empresarial dentro da Plataforma.
  • Usuário Operador: pessoa física vinculada ao Cliente Empresarial que opera a Plataforma (atendentes, administradores).
  • Plataformas Integradas: WhatsApp Business Platform (operada pela Meta Platforms, Inc.) e Telegram Bot API / MTProto (operadas pela Telegram FZ-LLC).

2. Dados que coletamos

2.1. Do Cliente Empresarial e Usuários Operadores

  • Nome, e-mail, telefone, função no workspace
  • Credenciais de autenticação (senha cifrada com bcrypt)
  • Logs de acesso, IP, user-agent
  • Dados de pagamento (processados por gateway terceiro)

2.2. Dos Leads do Cliente Empresarial

  • Nome, número de telefone (formatado em E.164)
  • Conteúdo das mensagens trocadas via WhatsApp ou Telegram
  • Metadados das conversas (timestamps, status de entrega, leitura)
  • Etiquetas/tags, etapa do funil (kanban), notas internas
  • Origem (UTM source/medium/campaign, fbclid, gclid quando disponíveis)

2.3. Das integrações Meta WhatsApp e Telegram

  • Identificadores técnicos: WhatsApp Business Account ID (WABA ID), Phone Number ID, Business Portfolio ID, Bot ID, Telegram User ID
  • Tokens de acesso (cifrados com AES-256-GCM antes de armazenar)
  • Status de qualidade e saúde das conexões (Quality Rating, Messaging Limit Tier)

3. Finalidades do tratamento

Tratamos os dados acima para:

  • Permitir que o Cliente Empresarial envie e receba mensagens com seus Leads pelos canais conectados
  • Organizar atendimento (kanban, atribuição entre atendentes, etiquetas)
  • Gerar relatórios e métricas operacionais (dashboards, taxas de resposta)
  • Integrar com a API Meta WhatsApp Business (criar/atualizar templates, registrar números, receber webhooks de status)
  • Integrar com Telegram (Bot API e MTProto) para envio e recepção
  • Garantir segurança, prevenir fraude e abuso, cumprir obrigações legais e regulatórias

4. Bases legais (Art. 7º LGPD)

  • Execução de contrato (Art. 7º, V) — dados do Cliente Empresarial e Usuários Operadores
  • Legítimo interesse (Art. 7º, IX) — dados de Leads, na medida estritamente necessária para o atendimento solicitado pelo Cliente Empresarial
  • Consentimento (Art. 7º, I) — quando exigido (ex.: marketing direto após opt-in)
  • Cumprimento de obrigação legal/regulatória (Art. 7º, II) — retenção de logs fiscais

O Cliente Empresarial é o Controlador dos dados de seus Leads. A Lowan atua como Operadora (Art. 5º, VII LGPD), tratando esses dados conforme instruções do Controlador.

5. Compartilhamento com terceiros

Compartilhamos dados estritamente necessários com:

  • Meta Platforms, Inc. — quando o Cliente conecta uma WhatsApp Business Account: envio e recebimento de mensagens, metadados de entrega, registro do número na Cloud API. Sujeito à Política Comercial do WhatsApp e Termos da Meta para Empresas.
  • Telegram FZ-LLC — quando o Cliente conecta um bot ou número pessoal Telegram, conforme Termos da Telegram API.
  • Provedores de infraestrutura (hospedagem, banco de dados, monitoramento) sob acordos de confidencialidade e cláusulas de proteção de dados.
  • Autoridades públicas mediante ordem judicial ou requisição legal devidamente fundamentada.

Não vendemos dados pessoais a terceiros sob nenhuma circunstância.

6. Armazenamento e segurança

  • Servidores localizados em data centers com certificações ISO 27001/SOC 2
  • Comunicação cifrada via HTTPS/TLS 1.2+ em todas as rotas
  • Tokens de acesso e senhas cifrados em repouso (AES-256-GCM para tokens; bcrypt para senhas)
  • Backup diário do banco de dados, com retenção mínima de 7 dias
  • Controle de acesso baseado em função (RBAC) com isolamento entre workspaces
  • Logs de auditoria armazenados por 90 dias

7. Seus direitos como titular (Art. 18 LGPD)

Como titular de dados pessoais, você tem direito a:

  • Confirmação da existência de tratamento
  • Acesso aos dados
  • Correção de dados incompletos, inexatos ou desatualizados
  • Anonimização, bloqueio ou eliminação de dados desnecessários
  • Portabilidade dos dados
  • Eliminação dos dados tratados com consentimento
  • Informação sobre compartilhamento
  • Revogação do consentimento

Para exercer esses direitos, contate o Encarregado (DPO) pelos canais informados na Seção 10.

8. Cookies e tecnologias de rastreamento

A Plataforma usa cookies estritamente necessários para autenticação (token JWT em localStorage) e preferências de interface. Não usamos cookies de publicidade ou rastreamento de terceiros sem consentimento explícito do Usuário Operador.

9. Retenção de dados

  • Dados de Cliente Empresarial e Usuários Operadores: durante a vigência do contrato + 5 anos após o término (prazo prescricional civil)
  • Dados de Leads: enquanto o Cliente Empresarial mantiver a conta ativa; após cancelamento, os dados são anonimizados em até 90 dias, salvo obrigação legal de retenção
  • Mensagens e logs de atendimento: 12 meses no banco operacional; backups com retenção rolling de 90 dias
